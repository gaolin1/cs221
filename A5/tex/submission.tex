1.a
\normalsize

% <SCPD_SUBMISSION_TAG>_1a
\begin{answer}
  % ### START CODE HERE ###
  There are $n+1$ agents, $a_0$ is Pac-Man and $a_1, \dots, a_n$ are the ghosts. One depth is one
  move from every agent, so $d$ only goes down after the last ghost $a_n$ moves.

  \[
    V_{\text{minimax}}(s, d) =
    \begin{cases}
      \text{Utility}(s)
        & \text{if } \text{IsEnd}(s) \\
      \text{Eval}(s)
        & \text{if } d = 0 \\
      \max_{a \in \text{Actions}(s)} V_{\text{minimax}}(\text{Succ}(s, a), d)
        & \text{if } \text{Player}(s) = a_0 \\
      \min_{a \in \text{Actions}(s)} V_{\text{minimax}}(\text{Succ}(s, a), d)
        & \text{if } \text{Player}(s) = a_i,\ 1 \le i < n \\
      \min_{a \in \text{Actions}(s)} V_{\text{minimax}}(\text{Succ}(s, a), d - 1)
        & \text{if } \text{Player}(s) = a_n
    \end{cases}
  \]

  The first two cases are the end conditions, either the game ended or we ran out of depth and use the eval function.
  Pac-Man takes the max, the ghosts take the min, and only the last ghost passes $d - 1$ down.
  % ### END CODE HERE ###
\end{answer}

\begin{answer}
  % ### START CODE HERE ###
  \[
    V_{\text{exptmax}}(s, d) =
    \begin{cases}
      \text{Utility}(s)
        & \text{if } \text{IsEnd}(s) \\
      \text{Eval}(s)
        & \text{if } d = 0 \\
      \max_{a \in \text{Actions}(s)} V_{\text{exptmax}}(\text{Succ}(s, a), d)
        & \text{if } \text{Player}(s) = a_0 \\
      \dfrac{1}{\lvert \text{Actions}(s) \rvert} \sum_{a \in \text{Actions}(s)} V_{\text{exptmax}}(\text{Succ}(s, a), d)
        & \text{if } \text{Player}(s) = a_i,\ 1 \le i < n \\
      \dfrac{1}{\lvert \text{Actions}(s) \rvert} \sum_{a \in \text{Actions}(s)} V_{\text{exptmax}}(\text{Succ}(s, a), d - 1)
        & \text{if } \text{Player}(s) = a_n
    \end{cases}
  \]

  Same as 1a, but the ghosts take the average of their successors instead of the min, since each
  ghost picks every legal move with probability $1 / \lvert \text{Actions}(s) \rvert$.
  % ### END CODE HERE ###
\end{answer}

5.a
\normalsize

% <SCPD_SUBMISSION_TAG>_5a
\begin{answer}
  % ### START CODE HERE ###
  Minimax assumes the ghosts play optimally, so in \texttt{trappedClassic} it thinks it will die no
  matter what. Because of the time penalty dying sooner scores better, so it runs into the closest
  ghost. Expectimax assumes the ghosts move randomly, so there is a chance they wander off and going
  for the pellets is worth more.
  % ### END CODE HERE ###
\end{answer}

5.b
\normalsize

% <SCPD_SUBMISSION_TAG>_5b
\begin{answer}
  % ### START CODE HERE ###
  Give Pac-Man a reward for each move it stays alive instead of a time penalty, with pellets still
  worth more so it doesn't just hide. A penalty for dying won't help since minimax thinks it dies in
  every branch anyway. With a survival reward dying later will make scores higher, so minimax runs from the
  ghosts instead of rushing them.
  % ### END CODE HERE ###
\end{answer}

  \begin{itemize}
    \item \textbf{Fairness} (demographic parity). System cards run a bias benchmark (BBQ) and a

    training data is only called a ``proprietary mix''.

    \texttt{/feedback} and support exist but are private, with no public record of what got fixed. A
    public issue log would help.
